# Triage Label Vocabulary

Maps the five canonical triage roles to the label strings used in this repo's issue tracker.

| Role | Label string | Notes |
|-------|---------------|-------|
| `needs-triage` | `needs-triage` | Default |
| `needs-info` | `needs-info` | Default |
| `ready-for-agent` | `ready-for-agent` | Default |
| `ready-for-human` | `ready-for-human` | Default |
| `wontfix` | `wontfix` | Default |

These strings are used by the `/triage` skill when applying labels during issue triage.
